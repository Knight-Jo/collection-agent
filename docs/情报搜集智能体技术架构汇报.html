以可核验证据为中心

  • 情报目标拆解为关键问题
  • 围绕覆盖缺口持续探索

02 / 18

THE HARD PROBLEMS

真正困难的不是联网，而是控制开放信息空间

01

如何搜得全

主题宽泛、表达多样、来源分散，搜索引擎只暴露部分入口。

02

如何搜得深

关键信息隐藏在官网栏目、附件、动态页面和多媒体中。

03

如何证明是真的

多篇报道可能同源转载，引文也可能只支撑声明的一部分。

04

如何知道可以停

搜索次数和文档数量无法证明问题已经获得充分证据。

技术任务不是“让模型多搜几次”，而是建立一个有状态、有约束、有反馈的搜索控制系统。

DISCOVERY SPACE

L2

站点结构发现

L3

实体关系扩展

L4

资源发现

HTML、PDF、Office、图片、音视频、公开数据和附件。

设计转变：不先问“支持什么文件格式”，而是先发现信息源中存在什么资源，再选择对应获取和解析方式。

EVIDENCE BY DESIGN

结论必须穿过五道确定性门禁

01 / MATERIAL

原始材料

公开来源、采集时间、原件与正文完整性。

02 / FACT

原子事实

单一主体、动作、时间和数字，可独立核验。

03 / QUOTE

精确引文

逐字存在于正文，带行号或音视频时间戳。

04 / REVIEW

隔离审核

判断完整支撑、部分支撑、无关或矛盾。

05 / COVERAGE

覆盖门控

结合独立来源、质量、时效、冲突决定报告资格。

可追溯链：报告结论 → 事实 → 引文 → 文档 → 原始材料与完整性校验。

VALUE & TECHNICAL MOAT

壁垒不在单次模型回答，而在完整的本地情报生产闭环

搜索控制面

将问题、来源角色、候选、证据增益和停止条件形成闭环。

证据治理底座

事实、引文、审核、冲突、覆盖与报告之间具有不可绕过的约束。

安全多媒体采集

网页、附件、动态页面、OCR 和 ASR 共享统一安全与质量边界。

本地受限模型运行

依靠状态恢复与确定性动作，让有限窗口和吞吐仍能完成长任务。

实验与数据闭环

持续积累真实轨迹、失败案例、质量指标和可复用的情报材料资产。

对技术团队

可测量、可调试、可替换模型、可逐步扩展。

对业务用户

更快理解信息全貌，并能回到原件核查。

对甲方组织

调研方法、来源体系、证据材料和历史成果持续留存本地。

最终价值：把公开信息检索能力，沉淀为甲方可掌控、可审计、可持续进化的专属情报能力。
