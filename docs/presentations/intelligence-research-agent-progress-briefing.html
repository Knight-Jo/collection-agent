汇报主线：不是介绍一个“更会生成文本的模型”，而是说明一套可持续建设的情报生产方法。

WHY THIS PROJECT

公开信息不缺，真正稀缺的是：找到关键材料、证明结论成立，并把结果交付给人使用。

海量网页、附件与多媒体持续增长
碎片关键内容分散在不同来源与格式
高风险单源、错引和过期信息影响判断

OBJECTIVES

建设目标：广、深、准、用

广

覆盖关键来源

覆盖问题、来源角色、语言、时间、地域与材料形态，不用 URL 数量制造“广”的错觉。

深

进入原始材料

从搜索入口深入官网栏目、附件、动态页面、图片与音视频，不把链接跳数当研究深度。

准

证据约束结论

每个重要结论都能回到原文，引文、来源独立性、时效与冲突均可核查。

用

服务阅读决策

形成执行摘要、结构化报告和材料导读，帮助用户快速判断先看什么、为何采用。

统一目标：在受控资源内，获得更多能够支撑核心问题的独立证据。

POSITIONING

从“联网回答”升级为“情报成果生产”

常见联网问答

以回答为终点

  • 搜索结果和来源混在自然语言中
  • 关键过程通常只存在于对话上下文
  • 材料、证据和停止理由难以复核
  • 任务结束后难形成长期资产
本地情报调研智能体

以可审计成果为终点

  • 搜索只提供候选，原文归档后才能取证
  • 事实、引文、审核、覆盖和报告分别留痕
  • 没有查清的内容必须在报告中披露
  • 每次任务持续增加本地情报资产
核心差异：模型生成能力可以替换，证据链、来源体系、过程数据和调研方法可以持续保留。

DESIGN PRINCIPLES

让 Agent 负责判断，让程序守住底线

Agent 负责

理解、规划与选择

  • 理解主题与用户真实调研目标
  • 选择查询、来源和下一步行动
  • 发现缺口、冲突及潜在解释
  • 组织适合阅读的报告结构
确定性系统负责

校验、限制与留痕

  • 网络安全、robots、并发与资源预算
  • 原件归档、哈希和逐字引文定位
  • 来源独立性、语义审核和覆盖门槛
  • 上下文压缩、断点恢复与终态完整性
原则：模型可以提出结论，但不能绕过证据工具，把未经验证的信息写入正式报告。

DEEP · ORIGINAL MATERIALS

入口

礼貌采集

资源有界

ACCURATE · EVIDENCE FIRST

每一句正式结论，都能回到原始材料

01 报告

正式结论

只引用通过当前覆盖门槛的事实。

02 事实

原子陈述

把复合说法拆成可以分别核验的事实。

03 引文

精确定位

逐字存在于正文，并保存行号或时间戳。

04 审核

隔离判断

独立模型判断完整、部分、无关或矛盾。

05 覆盖

质量门槛

检查来源独立性、质量、时间和冲突。

06 原件

完整性

正文和原件均绑定 SHA-256，可复核防篡改。

诚实终态：查清则充分完成；预算耗尽或连续无进展时，以 with_gaps 交付并明确说明缺口，不用流畅文本填补未知。

CURRENT GAPS

当前瓶颈已经从“能不能跑”转向“能否持续做好”

广

真实召回仍需复测

新增垂直搜索已经通过工程测试，但尚未用最新代码完成多主题真实联网对比。

深

实样本覆盖不足

真实 JavaScript、Office、独立音频和视频样本仍少，支持列表不等于生产稳定性。

准

独立验证不稳定

双源率、同源转载识别、同 URL 引用去重和自动评分人工校准仍需加强。

用

跨期与协作待增强

增量更新、报告差异、专题沉淀和管理层/研究员分层视图尚未产品化。

不做过早承诺：不以抓取量、支持格式列表、单次 done 或少量模型实验替代正式业务验收。
