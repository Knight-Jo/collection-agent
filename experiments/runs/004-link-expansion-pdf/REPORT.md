## 关键行为变化（trace 实证）

1. **来源扩展生效**：抓取 ehang.com/cn 后 → 直接跟进 **ir.ehang.com**（投资者关系）→
   ir.ehang.com/news-events/press-releases，全程未消耗搜索预算
2. **查询专业化**："EHang EH216-S 订单 交付 架 2025年"、"EHang EH216-S orders deliveries 2025 earnings"（EN）
3. **首个 covered fact**：央视春晚 22580 架无人机编队，双来源（新华网/中国民航报 + 人民日报海外版）
4. **首个 addressed 挑战点**：哈萨克斯坦首飞补充第三方证据（new_ev=1）
5. **收尾干净**：两轮挑战未收敛 → 模型按终态指引停止，向用户如实披露缺口（订单数据缺失、
   q1 单源），**未伪造证据、未循环重试 done**

## 004 结论

**迭代实验框架验证成立**：三轮累积修复（预算→提示词纪律→来源扩展）使检索质量发生质变——
从"4 篇同质文档 + 0 covered"到"6+ 篇跨域文档 + 1 covered + 1 addressed + 诚实终态"。
证据链框架（ID/哈希/门控/预算）全程零故障，证明核心架构可靠，瓶颈始终在检索行为。
